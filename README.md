# Mga Lugar, Mga Kuwento

Standalone Filipino photo essay webpage for PT5. Open `index.html` in a browser to preview it.

The top navigation opens three separate pages: `sanaysay.html`, `mga-larawan.html`, and `pagninilay.html`. They share styling from `styles.css` and scroll effects from `site.js`.

For easier browsing, the pages include a skip link, sticky mobile-friendly navigation, a reading progress bar, a back-to-top button, and an accessible photo lightbox (click or focus a photo and press Enter/Space).

## Magdagdag ng mga larawan

The page has captions for the ten photos. Save the image files in an `images` folder beside `index.html`, using these names:

1. `01-daungan.png`
2. `02-kubyerta.png`
3. `03-tulay-ilog.png`
4. `04-turbina-dagat.png`
5. `05-loob-moske.png`
6. `06-moske-patyo.png`
7. `07-bundok-lawa.png`
8. `08-pulang-tulay.png`
9. `09-tindahan.png`
10. `10-plaza-lungsod.jpg`

Keep the captions aligned with their photos. The current captions describe only what is visible and avoid guessing the exact locations.

## Bago isumite

PT5 requires at least ten photos, and all ten photo slots are now filled. WW5 also asks for five original photos taken by the group. If these supplied travel photos are not original photos taken by your group, use your group's original images for the assignment instead.

Add your group name and members in the footer. For submission, publish the folder to a static web host your class can access and submit the resulting public link; the local file itself is only a preview and is not an accessible public webpage.
